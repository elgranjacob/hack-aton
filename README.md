# Raven Vision — Hackathon

Prototipo web de **monitoreo vehicular inteligente** para la gestión de flotillas, desarrollado durante un hackathon.

## Funcionalidades
- Página de inicio y planes de suscripción.
- Registro e inicio de sesión de usuarios.
- Dashboards por rol: administrador de flotillas, administrador de proyectos, líderes y usuario Prime.
- Registro de rutas con captura de la ubicación actual (Geolocation API).
- Tabla de rutas y gráficas de seguimiento.

## Tecnologías
HTML · CSS · JavaScript · Bootstrap 5 · Chart.js · Supabase (base de datos y autenticación)

## Ejecutar
Abrir `index.html` en el navegador (o servirlo con una extensión como Live Server).
